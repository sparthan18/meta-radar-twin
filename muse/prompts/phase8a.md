Phase 8a: design foundations for the cinematic FUI look. Read docs/design-spec.md in full (it is the visual contract from now on), docs/story-spec.md (content contract), web/index.html, web/story.js, web/story.css and web/annotate.js as built through 7d, and the "## Web map" section of docs/gotchas.md before writing code. This phase changes how things look and what chrome exists in story mode; it does not change any scene's content, timing, data or captions.

Files you may change: web/index.html, web/story.js, web/story.css, web/annotate.js, web/deck3d.js, a new web/fui.css (tokens, type, components) and a new web/basemap.js (the restyled vector style), tests/. No change to web/data/, scripts/ or out/.

1. Typography and tokens. Load Rajdhani 500/600/700, JetBrains Mono 400/500 and Inter 400/500 from Google Fonts with `display=swap` and `preconnect`; define the colour tokens, type scale and spacing from the spec in web/fui.css; apply them everywhere so no element renders in `system-ui` or Helvetica (grep the CSS for both and remove). Numbers everywhere get `font-variant-numeric: tabular-nums`. Report every selector that changed family.

2. Story mode chrome. In story mode hide the header (title, blurb), the toggle rows, the month slider row, the headline card's old box and the MapLibre controls; add letterbox bars (8 % top and bottom, `--bg`), the scrub line along the bottom edge exactly as the spec describes (ticks, playhead, chapter name on hover, month readout right, CC and EXPLORE as mono words left), the lower-third caption on a bottom gradient with the hairline and the "04 / 09" scene index, and the scene tag removed (the index replaces it). Explore mode keeps all of its chrome for now (8d restyles it). Keyboard behaviour and `aria` from 7a–7d must survive: the scrub line is still the range input.

3. Vector basemap with 3D buildings. web/basemap.js builds the style object: start from the OpenFreeMap dark style (fetch `https://tiles.openfreemap.org/styles/dark` once at load, or embed the needed layers), keep only water, landuse park, buildings, major roads, rail and place labels, recolour to the spec's palette, set glyphs to the OpenFreeMap font host and labels to a mono-looking stack available there (report which), and add a `fill-extrusion` layer from the `building` source-layer with `render_height`/`render_min_height`, colour `#111a2c`, opacity 0.9, visible from zoom 13. The Esri imagery raster stays as the "Imagery" option; the Esri dark canvas is removed; the Sentinel chips (S1, S2) and all data layers (bridges, spans, scatterers, SAM, glow, markers, deck) are re-added on top of the new style in the same order as before. The 7d deck custom layer must render above the extrusions. Report the final layer order.

4. Film treatment and markers. Add the vignette and the 3 % grain overlay (CSS, `pointer-events: none`, grain off under reduced motion), widen the high-marker bloom, and replace the marker style with the reticle (dot, hairline ring, dashed rotating second ring for high) using the annotation layer or paint expressions; span dots lose the white rim. Add the scan line sweep on scene start (2 s, 2 %), none under reduced motion.

5. FUI primitives. In web/fui.css and web/annotate.js: `.fui-panel` (glass + corner brackets), `.fui-rule` (hairline with end ticks), `.fui-readout` (label over value with the count-up), the leader-line and ring restyles, the mono button style. Restyle the existing HUD block, history strip, headline card, proof panel, memo panel (story version), ending panel and side-view panels to use them, keeping their content. The strip loses its card and scrollbar and gains the 10 px cells and hairline playhead.

6. Motion. One easing family and the durations from the spec in CSS variables; the director's camera moves use the ease-out curve over 1.6–2.4 s; scene changes crossfade overlays over 600 ms; the dips into scenes 2 and 8 over 500 ms. Reduced motion as the spec says.

7. Frames for review. You have no browser. Instead, write `tests/frames.md`: for each scene and for the landing, the exact layout you built (positions, sizes, fonts, colours) so the reviewer can compare frames against the spec; and list what you could not verify.

8. Checks. `node --check` on every script, every `node tests/*.js`, `scripts/check_web_data.py` (data unchanged), `scripts/check_truncation.py`. Grep that no stylesheet or inline style still references `system-ui`, `Helvetica` or `#9ca3af`-style neutral greys outside the span scale.

- Report, do not tune: do not change thresholds, windows, SHRINK_K, the ladder, the model questions, the badge wording, any caption text or any file under out/ or web/data/.
- No spend this phase: no Meta API or SAM calls. Network: the page's own CDN, font and tile hosts only. Do not install packages. Do not create git commits. Call the build steps "phases".

Finish with: files created and changed; for each of items 1 to 6 what you built and how you checked it; the final layer order; the contents of tests/frames.md; the test and check results; and your self-review answers (a) to (d).
